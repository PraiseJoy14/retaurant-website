# Noir & Gold — Fine Dining Restaurant Website

A luxurious and modern fine dining restaurant website built using pure HTML, CSS, and JavaScript.  
Designed with elegant animations, premium typography, interactive UI elements, and a refined black-and-gold aesthetic inspired by luxury dining experiences.

---

## ✨ Features

- Elegant luxury-inspired UI/UX
- Fully responsive design
- Animated hero section
- Interactive custom cursor
- Smooth scrolling navigation
- Animated scroll reveal effects
- Dynamic menu tabs
- Reservation form UI
- Image gallery with hover effects
- Fine dining themed layout
- Mobile responsive navigation

---

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Unsplash Images
